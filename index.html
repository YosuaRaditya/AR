Solusi Jika Kamera Tidak Muncul

1. Izinkan Akses Kamera di Browser

Jika sebelumnya Anda tidak sengaja menekan "Blokir" atau "Deny":

  • Ketuk ikon Gembok (🔒) atau Setelan di sebelah kiri alamat URL browser (di bagian atas layar HP Anda).
  • Pilih Izin / Permissions -> Ubah Kamera menjadi Izinkan (Allow).
  • Muat ulang (Refresh) halaman web.
Tips Penting

2. Gunakan Browser Asli

Pastikan Anda membuka tautan di aplikasi Google Chrome (Android) atau Safari (iPhone), bukan di dalam browser WhatsApp / Instagram.
