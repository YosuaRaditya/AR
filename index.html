Solusi Membuka Kamera AR di Smartphone

Kenapa kamera tidak otomatis terbuka di HP?

Sistem keamanan browser (Google Chrome / Safari) memblokir total sensor kamera dan WebXR jika dibuka lewat alamat HTTP lokal (seperti http://192.168.x.x:8000). Halaman harus berjalan di HTTPS atau localhost.

Solusi 1 (Paling Mudah)

Tunneling HTTPS Gratis (Cloudflare / Localtunnel)

Jalankan perintah ini di terminal komputer Anda:

npx localtunnel --port 8000

Atau jika Anda memiliki cloudflared: npx cloudflared tunnel --url http://localhost:8000

Buka link https://... yang muncul di Google Chrome HP Anda. Kamera AR akan langsung aktif 100%!

Solusi 2 (Kabel USB)

Android USB Port Forwarding (Tanpa Internet)

Colok HP Android ke laptop dengan kabel USB (aktifkan USB Debugging), lalu ketik di terminal:

adb reverse tcp:8000 tcp:8000

Buka http://localhost:8000 di Chrome HP. Karena menggunakan localhost, Chrome mengizinkan kamera AR secara instan!

Solusi 3

Chrome Flags (Tanpa Kabel & Tanpa Internet)

Di Google Chrome HP Anda:

  1. Buka: chrome://flags
  2. Cari: Insecure origins treated as secure
  3. Masukkan alamat URL komputer Anda (misal: http://192.168.1.5:8000)
  4. Ubah ke Enabled dan klik Relaunch.
